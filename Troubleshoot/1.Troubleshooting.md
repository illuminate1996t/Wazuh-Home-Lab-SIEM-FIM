# Wazuh Home Lab Troubleshooting

Problem: Issue Experienced: Wazuh Manager Inactive
During the lab, the Wazuh API connection was down because the **Wazuh Manager was not active**.

Command checked:

```bash
sudo systemctl status wazuh-manager
```

Result:

Wazuh Manager was not active

Fix:

```bash
sudo systemctl restart wazuh-manager
```

&:

```bash
sudo systemctl start wazuh-manager
```


Final result: 

```Wazuh Manager was active & enabled
